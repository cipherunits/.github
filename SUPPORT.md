# Support

Thanks for using Cipher Units software. Here's how to get help.

## Questions and discussion

- Prefer [GitHub Discussions](https://github.com/orgs/cipherunits/discussions) for general questions, ideas, and community chat.
- Check the repository `README.md` and docs first — many answers live there.

## Bugs and feature requests

- Use the issue templates in the relevant repository (Bug report / Feature request).
- Include reproduction steps, environment details, and expected vs actual behavior when filing a bug.
- Search existing issues before opening a new one.

## Security vulnerabilities

Do **not** open a public issue. See [SECURITY.md](./SECURITY.md) and report privately to **cipherunit.dev@gmail.com**.

## Contact

For other inquiries: **cipherunit.dev@gmail.com**

Maintainers triage community channels as time allows; we may not respond to every message individually.
